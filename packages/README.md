# Paquetes compartidos

Este directorio está reservado para paquetes que tengan al menos dos consumidores reales dentro del monorepositorio.

No se trasladará automáticamente el Domain del móvil ni se compartirán modelos de Prisma. Si aparece una necesidad comprobada, aquí podrán vivir contratos independientes de infraestructura, utilidades comunes o un cliente generado desde OpenAPI.

Mantener el directorio vacío es preferible a crear abstracciones compartidas antes de necesitarlas.
